# CLI Reference

## Core commands

| Command         | Purpose                       |
| --------------- | ----------------------------- |
| `zine init`     | Create a project              |
| `zine edit`     | Open the project in an editor |
| `zine preview`  | Serve a browser preview       |
| `zine build`    | Create a PDF                  |
| `zine validate` | Validate without compiling    |
| `zine doctor`   | Diagnose project/environment  |
| `zine info`     | Show metadata and statistics  |
| `zine chapters` | Manage chapters               |
| `zine clean`    | Remove generated files        |

All commands accept an optional project path. If omitted, ZINE searches the current directory and its parents for a project.
