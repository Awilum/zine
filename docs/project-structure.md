# Project Structure

A ZINE project contains publication data, not a copy of the ZINE engine.

```text
project/
├── zine.yml
├── publication/
├── content/
├── chapters/
├── images/
├── assets/
├── themes/
├── output/
└── .zine/
```

The existing `content/` hierarchy remains supported because it is part of the established renderer architecture.
